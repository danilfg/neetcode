# LeetCode / NeetCode

Python solutions for LeetCode and NeetCode problems, with a focus on comparing time and memory tradeoffs across different approaches.

Each folder contains one problem topic, and the files inside usually show multiple solution variants such as `faster`, `memory`, `best_option`, or a specific technique like `two_pointers`.

Run any solution with Python 3, for example:

```bash
python3 003_two_sum/003_1_two_sum_faster.py
```
